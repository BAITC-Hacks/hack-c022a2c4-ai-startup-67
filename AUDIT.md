# Итоговая техническая проверка

Дата: 23 сентября 2026. Локальная машина macOS, Python 3.9; набор предоставленных parquet.

## Выполнено

- CLI `python pipeline.py --data ./data --out ./out`: успешно, **3.164 с wall time**, **2.825 с внутри pipeline**. Это ниже требования 5 минут на данном наборе; не оценка производительности на других объёмах.
- Независимый расчёт во временную пустую папку: четыре CSV побайтно совпали с `out/`. Диагностика времени не сравнивалась.
- Readback-валидация: `valid=true`, **2 248 узлов, 105 кластеров, Top 50**. Проверены уникальность и полнота GID, допустимые роли и диапазоны, объяснения, ссылки на кластеры, размеры/seed/оборот, представители, сортировка и согласованность рейтинга.
- Набор: **3 119 направленных рёбер, 4 840 транзакций, 81 seed, 19 изолятов, 444 усечённых узла**. Суммы и количества не смешиваются. Усечённые узлы не получают terminal только из-за отсутствия видимого оттока; seed не получают transit из неполного входящего потока.
- `python -m unittest discover -s tests -q`: **99 тестов, 0 failures, 0 errors**, 5.131 с. Включает 15 UI-тестов и 10 AI-тестов. API-провайдер подменён; внешних вызовов нет.
- `python -m pip check`: **No broken requirements found**. Основные зависимости используются; Supabase и отдельный frontend отсутствуют.
- Streamlit **действительно запущен** на `127.0.0.1:8501`; после изменения модулей выполнен полный перезапуск. Все четыре вкладки просмотрены в браузере. Направленные стрелки, цвета, выбранный узел и предупреждение о сокращении графа проверены визуально.
- В AppTest на реальном наборе проверены случайный, первый в рейтинге, seed, depth-4 и изолированный GID; большой кластер 0 и одиночный 104; Top 100 корректно показывает доступные 50. Исключений не было. Холодный запуск AppTest 0.761 с; последовательные rerun 0.142–0.212 с (не end-to-end задержка браузера).
- UI использует сохранённые оценки и кэш. Тест с запрещёнными вызовами PageRank, betweenness и Louvain проходит. Курсор стандартный, декоративной анимации и физической симуляции нет.
- README переработан на русском; DEMO.md сформирован из реальных результатов генератором `scripts/prepare_demo.py`.

## AI и ограничения проверки

OpenAI SDK установлен, function-calling цикл проверен тестами: JSON-инструменты, разрешённые имена и аргументы, направления, лимиты, ошибки, отсутствие ключа, явная отправка кнопкой и сброс отображения ответа при смене GID. В окружении и Streamlit secrets **нет ключа**, поэтому живой ответ модели не проверялся. В браузере отображается штатное сообщение недоступности AI; аналитика работает.

Системная инструкция ограничивает ответ фактами инструментов, но не гарантирует отсутствие ошибок генерации. Проверка точности живых ответов остаётся необходимой после настройки API. Качество классификации по ground truth не проверялось: разметки нет.

Графы ограничены 100 узлами / 500 рёбрами; это явно отмечено. Контрагенты в основном UI — Top 10 с раскрытием полного списка, у AI — Top 20 с полным числом. Кнопка Open full analysis сохраняет GID; вкладку Client Analysis пользователь открывает сам. Расчёты на 1M узлов не выполнялись.

Данные и результаты находятся в gitignored `data/` и `out/`; при передаче чистого репозитория нужно отдельно предоставить исходные parquet и запустить pipeline. Секреты, созданные HTML, отладочные логи и временные скрипты в репозиторий не включены.
